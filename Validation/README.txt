Best Practices:
-Convert validation data into text files. Github does not like .mats
-You can edit the .gitignore to make sure unwanted files get added by accident.
-Commands when working with github gitbash:
	git status -> Check status of repo (displays changes)
	git add file_changed -> Adds file to staging or git add * to add everything into 1 commit 
	git commit -m "Short comment of what was done"
	git push -> Pushes changes to the repo
